# Early Code_Blooded skeleton

This folder is the first design sketch from the `Main_Frame` branch. It is kept so that work is not deleted.

It is **not** the playable game:

- `ArenaPanel` is empty
- `MainFrame.h` has a typo (`ArenaPaneel`) and does not use wxWidgets widgets
- There is no `Robot` or `ScriptEngine`
- `main.cpp` constructs a plain `App` instead of a `wxApp`
- Local Debug builds of this tree were unsuccessful

The live wxWidgets project is `CodeBlooded/` at the repository root (`CodeBlooded.sln`).
